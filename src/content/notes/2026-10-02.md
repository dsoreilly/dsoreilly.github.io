I've spent few months writing more often, growing a bit of a "digital garden". Writing polished blog posts is too high pressure for day-to-day writing, so this initially seemed like a better format: small, discreet notes hyper-focused on one particular subject. Backlinks to create a wider network of ideas. Effective in principle, but I found I was more concerned with simply adding new content than actually capturing unique ideas.

Back to the drawing board.

I'm currently reading the speculative fiction novel _Piranesi_ by Susanna Clarke, in which the story is told through entries from the protagonist's journals. The way in which said protagonist uses a system to index and reference other entries reminded me of the "digital garden" backlinks idea and interconnected notes. For research purposes, I've seen this refered to as "lab notes". So maybe that's what this Astro site is now; "lab notes" (although I much prefer the "garden" metaphor).

---

I wrote a small Bash script to create a new Markdown file populated with the necessary Frontmatter (for the Astro collection) in a symlinked `~/Developer/notes` directory. Currently, I have it open the file in a new VS Code window so I can start immediately writing.

```bash
$ note
Note 2026-10-02.md created
```
