## 2

It's about time I had play around with local LLMs. This will be my first attempt at configuring a coding assistant on my 16GB/M1 Pro MacBook, let's see how far I can get for $0.

Based on these cost and hardware requirements, this seems like a sensible setup:

- **Model:** [Qwen2.5-Coder 7B](https://huggingface.co/Qwen/Qwen2.5-Coder-7B/)
- **Provider:** [Ollama](https://ollama.com/)
- **CLI agent:** [OpenCode](https://opencode.ai/)

```bash
$ ollama launch opencode --model qwen2.5-coder:7b
qwen2.5-coder:7b does not work well with OpenCode. Try an agent-capable model like glm-5.3-flash:c
  ollama launch opencode --model glm-5.3-flash:cloud
```

Huh. Maybe this is _not_ a sensible setup...

It might be a context issue, these are the defaults from Ollama:

> Ollama defaults to the following context lengths based on VRAM: < 24 GiB VRAM: 4k context

Let's explore more tomorrow.
